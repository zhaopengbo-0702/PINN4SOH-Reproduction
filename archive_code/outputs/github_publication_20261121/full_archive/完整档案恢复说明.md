# 完整档案恢复说明

这组档案用于按原路径恢复本实验保留的本地文件。它与用于在线浏览的精简成果仓库分开保存，模型、预测数组、日志、审计、历史材料、原数据和依赖包的具体收录范围以`index.json`的`files`和`excluded`为准。

原始论文、作者代码、第三方数据、第三方依赖各自遵守其原许可、版权及引用要求。本档案没有为全部内容重新授予统一许可。公开展示或再次分发时，应查原来源记录和原许可。

## 下载后先验证

将`index.json`、`restore_full_archive.py`和所有`full-cas-part-NNN.zip`放在同一目录。需要Python3.9或更新版本，仅使用标准库，无需安装Torch或科学计算环境。

```powershell
python restore_full_archive.py --index index.json --verify-only
```

验证器依次核对每个ZIP整体的大小和SHA256、ZIP成员清单、每个内容块SHA256，以及每个原文件按块重组后的完整大小和SHA256。`status: passed`表示这些实际字节全部通过；本命令不写恢复文件。请保留发布页提供的SHA清单以独立核对索引文件本身。

## 恢复到新目录

```powershell
python restore_full_archive.py --index index.json --output D:\PINN4SOH恢复
```

若分包在其他目录，可使用`--archives-dir D:\下载的分包`。恢复器会在输出目录下按原相对路径重建。空文件、中文文件名、同内容的多个原路径和多块大文件均可恢复。Windows深层路径使用长路径形式处理。

已存在且SHA相同的文件会核验后跳过；已存在且内容不同的文件会拒绝覆盖。绝对路径、上级跳转、Windows保留文件名、大小写路径冲突、ZIP符号链接和输出路径中的符号链接或junction均会拒绝。请使用新目录，完成检查前不要把恢复目标指向原始证据目录。

## 内容去重的含义

索引中的每个文件记录完整SHA和有序`chunks`。同SHA的内容块只存一次，但文件索引仍保留每个原路径。因此源目录中逐字节相同的副本会在恢复时重建为多份普通文件。它们不是硬链接，也不会依赖原始电脑上的旧文件。

`RESTORE_FIXTURE_ACCEPTANCE.json`记录小型恢复器测试；它不能替代对实际完整档案执行`--verify-only`所得结果。只有实际全包验证通过并确认远端文件可下载，才具备清理原件的恢复前提。恢复脚本本身不执行清理，也不会删除归档或源目录。
