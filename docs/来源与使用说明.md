# 来源与使用说明

本仓库是独立复现记录，原论文作者未参与本项目的结果整理。引用方法时应引用原论文，使用原作者代码和数据时应同时保留其来源。

- 论文：[Physics-informed neural network for lithium-ion battery degradation stable modeling and prognosis](https://doi.org/10.1038/s41467-024-48779-z)
- 作者代码：[wang-fujin/PINN4SOH](https://github.com/wang-fujin/PINN4SOH)
- 本次源码参考提交：`cc3cc5053caf38f04e0665f7f88cb109144d035e`。以保存的实际文件 SHA 识别实验版本。

`PINN4SOH/` 为当时保存的作者源码快照。模型、数据加载、MLP/CNN 和迁移结构来自作者；`reproduction/` 的实验调度、配置记录、兼容处理、证据收集、独立指标重算和图表工具是本项目的补充。两个 slope 的导出采用明确标注的替代定义，192 候选搜索是另行设计的实验，不能当作作者未公开历史协议的恢复。

第三方论文、数据、依赖安装包和作者源码的权利及使用条件归原来源。本仓库不对所有材料套用一个新的统一开源许可，不因公开备份而扩大原来源授权。完整档案中的来源和历史许可文件应一并保留。

发布结果保留原始数值与文件字节，历史路径与较早状态说明可能仍出现。新的中文说明注明更新范围；未把作者 Source Data 的重新绘图标成独立重训结果，也未把所有方法结论写成复现成功。
