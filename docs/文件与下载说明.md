## 完整档案

[完整档案发布页](https://github.com/zhaopengbo-0702/PINN4SOH-Reproduction/releases/tag/archive-20261121)用于保存实验资料的可恢复副本，包括已有原始数据、处理证据、环境与历史文件；第三方权利和使用条件仍归原来源。内容去重分包保存，使用索引与恢复脚本还原，范围和排除项以该发布页最终清单为准。

完整档案是备份，不代表每个历史尝试都是最终有效实验。缓存、重复中转、已舍弃的未完成追加实验不作为成果；主实验的不利结果仍保留。

## 历史路径与当前说明

原实验 metadata 保留 `/workspace/...` 和旧 Windows 路径用于证明来源。它们不会因上传自动变成当前可用路径。解压后将逻辑根对应到自己的实际路径，使用新输出目录运行审计，不覆盖原件。

`outputs/full_reproduction/...` 的报告是历史原件，原字节不改；较早报告中“192 尚未运行”等状态由[已完成的 192 独立复核](../outputs/full_reproduction/replacement_search_recovered_20261111/192搜索_本地独立复核.md)取代。192 搜索最终 pipeline 原 JSON 在本次整理中已重新下载，见 [PIPELINE_FINAL_ORIGINAL.json](../outputs/full_reproduction/replacement_search_recovered_20261111/PIPELINE_FINAL_ORIGINAL.json)。

保留证据和“复现出原论文全部结论”是不同的事。有关结论边界请阅读[未复现与限制](未复现与限制.md)。
