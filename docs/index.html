哪些结论还不能成立？

复现档案保留差异与来源缺口，方便判断结果能回答什么问题。

逐项阅读未复现与限制 →
  • “全部任务精度最好、全部小样本设置最好、迁移普遍优于目标域独训”均有本次实测反例。
  • 两种论文单调损失实现结果不同；作者修正版默认参数又是另一批协议，不能混成同一结果。
  • MIT 原始 MAT、两个特征斜率、历史搜索与种子、原总体聚合口径等尚无法唯一恢复。
  • 验证相邻端点重合、MIT 物理身份重复与整条轨迹缩放已有记录，不能宣称全面无数据泄漏。
  • CPU 计时采用不同于论文的硬件；未验证真实电化学机制识别、导数阶数优越或 BMS 部署。
